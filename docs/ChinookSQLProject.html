Chinook Music Store SQL Project¶

This report presents insights from an exploration of the Chinook Music Store database, hosted locally and queried using Python and SQLite.

Goals¶

  • Demonstrate core SQL querying techniques
  • Derive business-relevant insights
  • Present findings in a clear, readable format

Setup¶

This block imports necessary Python packages, connects to the Chinook SQLite database and performs some preprocessing steps.

Notably, I removed non-music/TV genres from the genre, track and invoiceline tables to focus the analysis on music.
The new views are genre_music, track_music and invoiceline_music.

1) What are the top 10 best-selling music artists ?¶

We define top-selling as artists those with the most total revenue.
Queries use a CTE to calculate total_global_revenue followed by filtering for the top 10.

Two query versions provided:

  • Version A: allows for ties
  • Version B: yields exactly 10 cases in the result by using artist's name as a tiebreaker
In [19]:
# Version A: Filters by DENSE_RANK and can include ties

query = """


WITH total_global_revenue_cte AS(
    -- Calculating global revenue by artist
    SELECT 
         ar.ArtistId,
         ar.Name AS artist_name,
         GROUP_CONCAT(DISTINCT ge.genre_name) AS genres,
         SUM(il.UnitPrice * il.Quantity) AS total_global_revenue,
         DENSE_RANK() OVER(ORDER BY SUM(il.UnitPrice * il.Quantity) DESC) AS dense_rank   
    FROM invoiceline_music AS il
    JOIN track_music AS tr 
      ON il.TrackId = tr.TrackId
    JOIN album AS al 
      ON tr.AlbumId = al.AlbumId
    JOIN artist AS ar 
      ON al.ArtistId = ar.ArtistId
    JOIN genre_music AS ge 
      ON ge.GenreId = tr.GenreId
    GROUP BY ar.ArtistId, ar.Name
)
SELECT
     artistId,
     artist_name,
     genres,
     total_global_revenue 
FROM total_global_revenue_cte
-- Filtering for dense ranks in the top 10, which can include ties
WHERE dense_rank <= 10    
ORDER BY total_global_revenue DESC, artist_name

"""
artist_sales = pd.read_sql_query(query, engine)

Share of Global Revenue from Top Four Genres¶

This query calculates what percentage of total global revenue comes from the top four genres. It uses three CTEs:

  • genre_rev aggregates total revenue by genre
  • global_rev computes global revenue across all genres in the database
  • top4_rev sums revenue for the top genres by total sales

Finally, the query computes the percentage of global revenue represented by these top four genres.

In [24]:
query = """

WITH genre_rev AS (
    -- Calculating global revenue by genre
      SELECT 
         ge.genre_name,
         ROUND(SUM(il.UnitPrice * il.Quantity), 2) AS revenue
    FROM invoiceline_music AS il
    JOIN track_music AS tr 
      ON il.TrackId = tr.TrackId
    JOIN genre_music AS ge 
      ON tr.GenreId = ge.GenreId
    GROUP BY ge.GenreId, ge.genre_name 
), global_rev AS (
     -- Calculating total global revenue
     SELECT SUM(revenue) AS global_revenue FROM genre_rev
), top4_rev AS (
     -- Calculating total revenue in the top 4 genres
     SELECT 
           SUM(revenue) AS top4_revenue 
     FROM ( 
         SELECT
               revenue  
         FROM genre_rev
         ORDER BY revenue DESC, genre_name
         LIMIT 4
     )
)
SELECT 
     ROUND((t.top4_revenue/gl.global_revenue)*100, 2) AS percentage_of_global_revenue
FROM top4_rev AS t
CROSS JOIN global_rev AS gl
     
"""
top_genres = pd.read_sql_query(query, engine)

5) Do top countries display distinct top genre profiles ?¶

Above we observed:

  1. The top four genres account for 81% of Chinook's total revenue.
  2. The top six countries account for 65% of global revenue.

Here, we examine whether those leading markets differ in their genre composition by calculating each country's revenue share across the top genres.

This calculation uses three CTEs:

  • country_genre_rev calculates the total sales for each genre in each country
  • country_rev identifies the top six countries in terms of total sales
  • genre_gen identifies Chinook's top four genres in terms of total sales

Finally, we filter country_genre_rev to include only the top six countries and top four genres.
The resulting subset is saved as a temporary table for further analysis (e.g., percentage-of-revenue comparisons by country).

In [29]:
DB_PATH = repo_root / "data" / "Chinook_Sqlite.sqlite"
conn = sqlite3.connect(DB_PATH) 

query = """
 
DROP TABLE IF EXISTS temp_country_genre_rev;
CREATE TEMP TABLE temp_country_genre_rev AS
WITH country_genre_rev AS(
-- 1) revenue per country x genre
    SELECT 
         c.Country,
         ge.genre_name,
         SUM(il.UnitPrice * il.Quantity) AS revenue
    FROM customer AS c
    JOIN invoice AS i 
      ON c.CustomerId = i.CustomerId
    JOIN invoiceline_music AS il 
      ON i.InvoiceId = il.InvoiceId
    JOIN track_music AS tr 
      ON il.TrackId = tr.TrackId
    JOIN genre_music AS ge 
      ON tr.GenreId = ge.GenreId
    GROUP BY c.Country, ge.genre_name
),
country_rev AS(
-- 2) total revenue per country (to pick top 6)
    SELECT
         Country,
         SUM(revenue) AS revenue
    FROM country_genre_rev
    GROUP BY Country
    ORDER BY revenue DESC, Country
    LIMIT 6
),
genre_rev AS(
-- 3) total revenue per genre (to pick top 4)
    SELECT
         genre_name,
         SUM(revenue) AS revenue
    FROM country_genre_rev
    GROUP BY genre_name
    ORDER BY revenue DESC, genre_name
    LIMIT 4
)
SELECT
     *
FROM country_genre_rev AS cgr
-- 4) Filtering by top countries and genres
WHERE 
     cgr.Country IN (SELECT Country FROM country_rev)
     AND cgr.genre_name IN (SELECT genre_name FROM genre_rev)

"""
conn.executescript(query) 
conn.commit()

8) Which artists should be targeted for promotion in each country?¶

The Chinook Marketing Team is planning a promotional campaign and has requested guidance on the most popular (“hot”) artists in each country.

To approximate artist popularity, we will:

    1. Identify each country’s top two genres over the past two years, based on total revenue.
    1. Within those genres, determine the top artist by total sales.

These calculations use two CTEs with window functions:

  • recent_genres identifies the top two genres in each country.
  • recent_artists identifies the top artist within each genre and country.

Finally, we’ll merge and filter these CTEs to produce a summary of top genres and corresponding artists per country.
Ties are included to give the Marketing Team flexibility in selecting artists for the campaign.

In [34]:
query = """

WITH recent_genres AS(
    -- Ranking genres by sales during the last two years for each country
    SELECT 
        i.BillingCountry AS Country,
        ge.genre_name,
        ROUND(SUM(il.UnitPrice * il.Quantity), 2) AS revenue,
        DENSE_RANK() OVER(PARTITION BY i.BillingCountry ORDER BY ROUND(SUM(il.UnitPrice * il.Quantity), 2) DESC) AS genre_rk
    FROM invoice AS i
    JOIN invoiceline_music AS il ON i.InvoiceId = il.InvoiceId
    JOIN track_music AS tr ON il.TrackId = tr.TrackId
    JOIN genre_music AS ge ON tr.GenreId = ge.GenreId
    WHERE CAST(strftime('%Y',i.InvoiceDate) AS INTEGER) >= 2024                                       -- using data from 2024 and 2025; it is placeholder data; 2025 has data for the whole year
    GROUP BY i.BillingCountry, ge.genre_name
), 
recent_artists AS(
    -- Ranking artists by sales during the last two years for each genre in each country
    SELECT 
        i.BillingCountry AS Country,
        ge.genre_name,
        ar.Name AS artist,
        ROUND(SUM(il.UnitPrice * il.Quantity), 2) AS revenue,
        DENSE_RANK() OVER(PARTITION BY i.BillingCountry, ge.genre_name ORDER BY ROUND(SUM(il.UnitPrice * il.Quantity), 2) DESC) AS artist_rk
    FROM invoice AS i
    JOIN invoiceline_music AS il ON i.InvoiceId = il.InvoiceId
    JOIN track_music AS tr ON il.TrackId = tr.TrackId
    JOIN genre_music AS ge ON tr.GenreId = ge.GenreId
    JOIN album AS al ON tr.AlbumId = al.AlbumId
    JOIN artist AS ar ON al.ArtistId = ar.ArtistId 
    WHERE CAST(strftime('%Y',i.InvoiceDate) AS INTEGER) >= 2024                                       -- using data from 2024 and 2025; it is placeholder data; 2025 has data for the whole year
    GROUP BY i.BillingCountry, ge.genre_name, ar.Name
)

SELECT ta.Country,
       ta.genre_name,
       ta.artist
FROM recent_artists AS ta
JOIN recent_genres AS tg ON ta.Country = tg.Country 
     AND ta.genre_name = tg.genre_name
-- Filtering for top two genres in each country AND top artist in each of those genre
WHERE tg.genre_rk <= 2
      AND ta.artist_rk = 1;

"""
